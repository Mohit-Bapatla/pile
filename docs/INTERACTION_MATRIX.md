# Interaction matrix

This inventory contains **54 control/state groups**. A group may contain several related controls. It is not a claim that every control was tested against every possible click, keyboard, loading and failure combination. Automated evidence is in the named test files under `tests/e2e/`, `tests/unit.test.ts`, and `tests/integration.test.ts`. Destructive interactions run only on the temporary QA database.

## Important state combinations

Linked and unlinked completion, Board reopening, edit after sync, source cascade deletion, duplicate reupload, optional candidate promotion, concurrent parsing, ambiguous-date approval blocking, source-only search, empty selection, provider errors and long review scrolling have explicit checks. Timezone changes are persisted and applied on refresh; cross-tab live synchronization while another dialog is open is not implemented. The local app intentionally has no workspace selector, theme switch, profile editor, Inbox filters or pagination controls. Native Safari, physical microphone capture and live Google/Backboard/Tiger account interactions remain outside the completed checks.
